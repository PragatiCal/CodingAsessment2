Program1(Houses of ice and fire) fetches all houses and their respective regions from the Ice and Fire API using Python requests library. 
The data is stored in a list, sorted alphabetically based on house names and then written into a text file for easy 
readability and storage.

Program2 (Books of ice and fire) retrieves all book details from the Ice and Fire API and creates a dictionary 
containing book name, number of pages, release date, ISBN and publisher information. 
The collected data is then converted into a CSV file using the pandas library for structured data representation.

Program3 (Characters of ice and fire) fetches character details from the Ice and Fire API and calculates the number of TV series
appearances for each character using the tvSeries field. The data is sorted in descending order based on appearances
and exported into an Excel file using pandas and openpyxl libraries
